# EPUB 转 HTML · AI 批注阅读器

每本 EPUB 生成一个自包含的 HTML。输出包括正文、目录、图片、表格、脚注链接和阅读器。已有的 Robin 精读划线和索引会迁移为 AI 批注。阅读器内可以继续划线、写笔记、编辑、删除和加书签。

## 工作流

1. 确认输入路径、是否要批注、以及输出位置。已有精读索引或划线版且用户要保留先前批注时，优先转换这些版本。一书多版本时按用户指定选择。未指定目录时，在当前任务工作区创建独立输出目录。
2. 要生成新批注时，读取 [批注规则](references/annotations.md)。先用 `extract` 列目录，再逐章提取正文和段落 ID，按真实内容写批注。用户只要转换时，直接执行 `convert`。遇到已批注源文件，保留其已有阅读标记，除非用户要求重做或补充。
3. 从技能目录运行 Python 3 脚本。处理单本、指定多本或目录都使用相同入口。文件名有空格时，逐个加引号。

   ```bash
   python3 scripts/epub_reader.py convert "第一本.epub" "第二本.epub" --out-dir "HTML阅读版"
   python3 scripts/epub_reader.py convert "EPUB目录" --out-dir "HTML阅读版" --annotations "批注目录"
   ```

   批注目录里的命名为 `原始文件名（不含 .epub）.annotations.json`。单本也可以直接传入 `--annotations` 文件。未传入时，会读取 EPUB 旁同名的批注 JSON。已有输出只有在使用 `--overwrite` 时重建。
4. 检查每本的 JSON 结果。报告书名、输出路径、批注数、找不到的图片或未通过逐字校验的批注。转换继续处理其他书，存在失败结果或拒收批注时退出码为 1。核对侧栏条目与正文的对应，至少抽查一本的目录、图片和跳转，有现成批注时抽查标记。发现同一引文重复时补充段落编号、位置或上下文再重新转换。
5. 交付可直接在浏览器打开的 HTML。版权书按本机个人阅读场景处理。阅读器自动暂存，使用批注面板的 JSON 导出和导入来备份、迁移或在浏览器清除数据后恢复。可以另外导出 Markdown。重建前优先备份旧版批注，重建后确认个人笔记仍可恢复。工具不处理 DRM。

## 阅读器交互

- 点击“卡片”进入瀑布流，复习全书笔记、划线和书签。卡片按原文顺序载入，每批 24 张，随窗口宽度排成 1 至 3 列，新卡片接在当前最短的一列下方。每张卡片显示章节与来源，有笔记时附原文引文。滚动即可继续浏览，点卡片跳到原文，“返回正文”回到进入前的阅读位置。

- 选中同一段内文字可选择高亮色，或点“写笔记”。批注面板与双栏模式下的段旁卡片可编辑记录。
- 点击顶部“书签”可标记当前段落。段首显示横线与书签图标，同一段重复添加时提示已标记。
- 最右侧色点表示全书定位。点色点或列表条目会跳到原文，可点“返回阅读位置”。Alt 加上下箭头浏览上一条、下一条。
- 双栏是左正文、右批注，窄屏可通过批注面板定位。顶部可切换单栏。在外观中，直接点击米黄、白色、护眼绿或深色的色块切换背景，也可调节字号、字体、行距和正文宽度。

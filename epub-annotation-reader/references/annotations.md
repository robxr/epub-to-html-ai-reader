# 精读批注与路线格式

## 先看证据，再选段

先用 `extract` 取得当前版本的逐段正文。给每个候选段落问三个问题：它回答了读者的哪个问题？它在论证中是定义、证据、反例还是限制条件？去掉这条后，读者会错过什么？贡献重复时留下更完整的一处。不相关章节可以留白。

- `quote.exact` 逐字复制同一段内的原文，保留内部空白、标点和限定词。用 `chapter`、`paragraphId` 和必要的 `prefix`、`suffix` 消除歧义。可附 JavaScript UTF-16 偏移 `position.start`。缺失或同等可能的匹配会被拒收。
- `claim` 概括作者在这段明确主张的内容，保留对象、条件、程度和例外。逐字核验只证明引文存在，语义仍须回读上下文核对。
- `note` 写面向目标的 AI 解读。指出这段如何帮助读者理解问题；自己的推论、练习或跨章节联系要标清来源。缺乏书内证据时缩小结论或明确留空。
- `question` 写适合闭卷作答的问题，答案应能由引文及解读核对。避免把答案藏在题干里。纯书签、个人感想等不必强制出题。
- `tag` 用原文贡献命名，如“反例”“适用边界”。不要仅靠贴标签代替说明。每条 `id` 在一本书内唯一，重建时沿用同一含义的 ID。
- 对整书校准时抽查一条定义、一条有前提的论证和一条复习题（存在时）。问自己是否有遗漏限定词、偷换概念、题目不能由引文作答等问题。

## 示例

字段值中的引文和章节标识在实际使用时替换为当前 EPUB 的内容。

```json
{
  "bookId": "extract 返回的 bookId",
  "study": {
    "goal": "怎样从同一场景里选出两张作用不同的照片？",
    "mode": "找素材",
    "sessionMinutes": 10,
    "stage": "full",
    "preferences": "我懂基本构图，请多选能直接用于选片的判断依据。",
    "sessions": [
      {
        "title": "给两张照片分配不同的叙事任务",
        "minutes": 6,
        "reason": "用现场感比较两张候选照片，练习取舍。",
        "noteIds": ["selection-01"]
      }
    ],
    "gaps": ["这段内容没有讨论照片的印刷尺寸。"]
  },
  "annotations": [
    {
      "id": "selection-01",
      "chapter": "extract 返回的章节 ID",
      "paragraphId": "extract 返回的段落 ID",
      "quote": {"exact": "先挑一张能交代地点的，再挑一张能让你记起当时声音的。"},
      "author": "ai",
      "type": "note",
      "tag": "选片依据",
      "color": "yellow",
      "claim": "作者为两张照片分别指定了交代地点和唤起现场记忆的作用。",
      "note": "如果两张照片都只交代地点，可以换入一张能唤起现场记忆的细节照，再比较组合。",
      "question": "同一场景的两张照片可以分别承担什么作用？"
    }
  ]
}
```

`study` 可省略，旧批注也可以直接使用。`stage` 使用 `preview` 或 `full`。时长用分钟表示；按读者预算拆成一段段能完成的任务，并明确时长属于估计。路线中每个 ID 必须指向本书实际收录的批注。无法解答的问题写入 `gaps`，不要为了填满路线而补造一条批注。

颜色支持 `yellow`、`green`、`blue`、`pink`、`purple`。保留已有精读索引中经过审阅的记录。作为构建输入的批注 JSON 与浏览器个人备份用途不同：恢复个人编辑、删除与复习状态时，在阅读器中导入备份。调整试读风格时，从路线页导出偏好，将文件随反馈或下一本书交给助手。
